export MAILGATE_API_KEY="(.env의 API_SHARED_KEY 값)"

curl -X POST "$MAILGATE_URL/api/v1/send" \
  -H "Authorization: Bearer $MAILGATE_API_KEY" \
  -H "X-Client-ID: plm-solution" \
  -H "Content-Type: application/json" \
  -d '{
    "template_name": "approval-request",
    "to": ["reviewer@example.com"],
    "data": {
      "item_id": "REQ-1024",

      "review_url": "https://plm.example.com/items/REQ-1024"
    }
  }'

MCP

AI로 물 흐르듯 완성되는 메일 연동

쉬운 연동과 빠른 개발을 위해 MCP 서버를 제공합니다.

  • approval-request 메일 제목에 문서 번호를 넣어 줘
  • 오늘 실패한 메일을 찾아서 원인을 정리해 줘
  • 새 시스템용 호출 모듈을 등록하고 dry-run으로 한 통 보내 줘
  • 사람별 MCP token
  • Claude Code, OpenCode 연결
  • 운영 환경은 조회와 Git Sync 적용만
  • 비밀값은 AI에 보이지 않음

MCP를 사용하려면 계정 메뉴에서 MCP token을 발급해야 합니다.

기능

발송, 템플릿, 재시도, 이력. 모두 MailGate에서 관리합니다.

  1. 템플릿 편집

    수정은 개발환경에서만, 운영환경에서는 Readonly

  2. Git Sync

    개발환경과 운영환경 연동을 원클릭으로

  3. 대시보드

    최근 14일 발송 현황과 최근 실패 목록

  4. 실패 원인과 재시도

    일시적 오류는 30초, 60초, 120초 뒤 다시 발송

  5. 발송이력

    API 호출 단순 발송과 배치성 수집 방식으로 보낸 알림을 한 화면에서 확인

  6. 첨부파일

    첨부파일 발송 지원(pdf, xlsx, docx, png 등)

  7. 발송 채널

    SMTP뿐만이 아니라 고객사 메일 API와도 연동 가능
